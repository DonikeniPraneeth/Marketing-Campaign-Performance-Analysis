📊 Marketing Campaign Performance Analysis


📌 Project Overview
A data-driven analysis of multi-channel marketing campaigns to evaluate effectiveness, cost efficiency, conversion behaviour, and ROI — transforming raw campaign data into actionable business insights.

🎯 Objectives
Analyze overall campaign performance across channels
Measure customer engagement using CTR and Conversion Rate
Evaluate cost efficiency using CPC and CPA
Identify high-performing and underperforming campaigns
Provide data-driven budget optimization recommendations
🛠️ Tools & Technologies
Python (Pandas, NumPy) — Data cleaning & analysis
Matplotlib & Seaborn — Data visualization
Jupyter Notebook — Analysis environment
📂 Project Files
File	Description
marketing_campaign_performance_analysis.ipynb	Full Python analysis notebook
Marketing_Campaign_Performance_Analysis_Report.pdf	Detailed project report
📐 Key Metrics Analyzed
Metric	Formula
CTR (Click Through Rate)	Clicks / Impressions
Conversion Rate	Conversions / Clicks
CPC (Cost per Click)	Cost / Clicks
CPA (Cost per Acquisition)	Cost / Conversions
ROI	(Revenue − Cost) / Cost
💡 Key Insights
Email campaigns delivered the highest ROI with the lowest CPC
Search & Paid Ads had higher conversion rates but at significantly higher costs
Social Media showed strong CTR but poor conversion efficiency
A small number of campaigns generated the majority of total revenue
Several campaigns operated at negative ROI despite high engagement
⚠️ Key Issues Identified
Overspending on low-conversion campaigns
Over-reliance on impressions instead of profitability metrics
Lack of ROI-driven budget allocation across channels
✅ Strategic Recommendations
Increase investment in high-ROI Email and Search campaigns
Pause or redesign negative-ROI campaigns immediately
Optimize landing pages to reduce funnel drop-offs
A/B test creatives and CTAs to improve conversion rates
Set automated alerts for abnormal CPC/CPA spikes
